# EM3 0.2.0

This release adds a complete Tasks workspace and refreshes EM3 with a calmer, adaptive monochrome interface.

## What’s new

- Capture and organize tasks with priorities, statuses, schedules, deadlines, notes, tags, and subtasks.
- Keep one Current Item in focus while managing today’s work from the Tasks overview.
- Connect tasks to people, teams, projects, pull requests, and external provider links.
- Use read-only Jira and GitHub integrations with clearer permission guidance and stricter request safeguards.
- Set up GitHub access with fine-grained personal access tokens.

## Improvements

- Completed and cancelled tasks remain visible for the rest of the day.
- Task edits preserve newer status and schedule changes made elsewhere in the interface.
- Deleting a parent task also removes its subtasks from the active workspace.
- Selection colors update correctly when macOS switches between Light and Dark appearances.
